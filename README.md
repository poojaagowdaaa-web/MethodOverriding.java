# MethodOverriding.java
# Day 15/45 – Method Overriding in Java 🚀

## 📌 About
This program demonstrates **Method Overriding** in Java using a real-world example of a Bank and a Savings Account.

## 🎯 Concepts Covered
- Inheritance
- Method Overriding
- `@Override` annotation
- Parent class and child class

## 💻 Example
- `Bank` is the parent class.
- `SavingsAccount` is the child class.
- The child class overrides the `interestRate()` method to provide its own implementation.

## 🖥️ Output
```text
Bank interest rate is 5%
Savings Account interest rate is 7%
```

## 🛠️ Technologies Used
- Java
- Eclipse IDE

## 📚 Learning Outcome
Learned how a child class can provide its own implementation of an inherited method through Method Overriding.
